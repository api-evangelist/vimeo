# Vimeo GraphQL API

Vimeo is a professional video hosting platform. The API covers video upload and management, albums, showcases, channels, user management, analytics, OTT platform configuration, live streaming, captions, thumbnails, and embed configuration.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Vimeo REST API
**Documentation:** https://developer.vimeo.com/api/reference

- Reference: https://developer.vimeo.com/api/reference
- Schema: https://github.com/api-evangelist/vimeo
